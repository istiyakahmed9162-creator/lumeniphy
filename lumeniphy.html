FOR TEACHERS

USER MANUAL

Everything a teacher needs to run a fully hands-free physics demo — from launch to voice-controlled sliders.

01

Getting Started

  • Click LAUNCH LAB to enter the app.
  • Click the 🎤 mic icon in the command bar, or say a wake command, to start listening.
  • Type into the command bar instead of speaking if the room is noisy.
  • Open ⚙️ Settings to enable "Always Listen" for continuous hands-free control.
02

Navigation Commands

  • "Open optics" / "electricity" / "quantum" / "mechanics" / "waves" / "thermodynamics" / "magnetism"
  • "Option 3" — opens the 3rd experiment in the current category list
  • "Open [experiment name]" — e.g. "open pendulum", "open ohm's law"
  • "Go back" / "Home" / "Main menu"
03

Voice Parameter Control

  • "Set voltage to 12" — sets a slider directly to a value
  • "Increase resistance by 20" / "decrease angle by 5"
  • "Increase wavelength" / "decrease mass" — nudges by a step
  • "Maximum frequency" / "minimum voltage" — jumps to the slider's limit
  • Works on every slider in every experiment — say a word from the on-screen label.
04

Tips for the Classroom

  • Enable Optimization Mode in Settings on older classroom PCs / projectors.
  • Enable Always Listen so you never touch the keyboard once class starts.
  • Drag with the mouse / finger to rotate any 3D scene; scroll or pinch to zoom.
  • Say "repeat" or check the status bar if a command isn't recognised.
